# 《测测你的灵魂对应哪位中国历史人物》

一款纯前端、零依赖、无需后端即可直接运行的国风趣味人格测试网页，适配手机端与电脑端。

## 快速运行

- **直接打开**：双击 `index.html` 即可在浏览器中直接运行（支持离线使用）。
- **本地预览（可选）**：也可在当前目录执行 `python3 -m http.server 8080` 后访问 `http://127.0.0.1:8080/`。

## 文件说明

- `index.html`：主页面结构（测试首页、逐题作答页、观象推演过渡页、结果展示页、海报导出与14位图鉴弹窗）
- `styles.css`：宋韵宣纸 × 朱砂印红 × 鎏金雅韵新中式国风响应式样式表
- `data.js`：40 道生活化情景单选题（涵盖日常习惯、处事方式、社交模式、情绪反应、兴趣偏好 5 大篇章）与 14 位历史人物档案（覆盖谋士、帝王、文人、侠客、诗人、将领、隐士 7 大原型）
- `app.js`：7 维标准化评分引擎、SVG 七维灵魂星图、Canvas 高清分享海报导出（1080×1690 PNG）、本地进度保存与一键复制文案
- `promo-screenshots/`：可直接用于小红书、朋友圈宣发的网页与高清海报宣传图

## 定位说明

本测试为趣味文化人格探索，非历史知识考试，亦非专业心理诊断。
